# Smart Library System

A MERN Stack Single Page Application (SPA) for managing a library book collection.

## Features
- Add new books (Title, Author, ISBN, Year).
- View all books in a responsive list.
- Delete books dynamically.
- Mobile responsive design.

## Setup Instructions

### Prerequisites
- Node.js installed
- MongoDB installed and running locally
